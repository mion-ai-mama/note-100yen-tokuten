# AIで作る！100円note販売スタートガイド（要件定義）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論・ビルド不要の静的サイト）
- 操作者: ブラウザのエンドユーザー / AI本体: なし / MCP: なし / 自社DB: なし / フロントUI: あり
- 種別: Web型（GitHub Pages） / 配布: マイ専用

## 1. 目的

リールから誘導する無料特典。ChatGPT（テーマ）→ Gemini（情報収集）→ Claude（下書き）→ noteで有料記事を公開、までを体験できる1ページガイド。最終ゴール: 読者が有料noteを1本作り、販売開始まで進める。売上・利益は保証しない。ターゲット: 40〜50代のAI初心者女性（スマホ中心）。

## 2. 構成

ファーストビュー → 教科書CTA → 全体の流れ → 目次 → はじめに → 準備編（登録・設定）→ STEP1 ChatGPT（HARM・プロンプト①②・入力例）→ STEP2 Gemini（プロンプト③）→ STEP3 Claude（プロンプト④）→ 実践編（販売手順・手数料）→ 公開前チェックリスト → LINE誘導

## 3. 実装

プロンプト4つにワンタップコピー（長文は折りたたみ、【 】と（ここに入力）を着色）。各STEP末尾に「次にやること」。チェックリストは保存なし。デザインは楽天アフィ特典と共通（アイボリー×ブラウン＋くすみピンク）。

## 4. 公式確認済みの事実（2026-10-21、noteヘルプセンターを実ブラウザで確認）

- 価格: 記事・マガジン・メンバーシップとも通常会員 100円〜50,000円、プレミアム/note pro は上限100,000円（「価格の設定とお支払い方法について」2026-08-03更新）→ **100円販売は可能**
- 手数料: 事務手数料（購入者の決済手段で異なる。クレジットカード5%・携帯キャリア15%・PayPay7%・Amazon Pay7%・noteポイント10%・PayPal6.5%）＋プラットフォーム利用料（（売上−事務手数料）×10%、有料記事）。小数点以下切り捨て。振込手数料270円/回。100円・カード決済の目安は 5円＋9円＝14円（「コンテンツを販売する際に引かれる手数料」2025-01-06更新）
- 有料記事の手順（ブラウザ）: [投稿]→記事作成→[公開に進む]→[有料]に切替→[有料エリア設定]→[このラインより上を有料にする]の位置調整→[投稿する]。有料ラインは段落間のみ。投稿者本人は購入導線が見えないため、ログアウト／シークレットで確認
- 設定: 「公式SNSでの紹介・外部サイト配信・他メディア紹介の許諾」（初期ON・アカウント設定でOFF可・有料は無料部分のみ紹介）／「記事の自動翻訳」（初期ON・設定の記事設定で変更・英語は単体有料記事も対象）／「生成AIの学習に拒否意向を示す」（設定のアカウントでON・全AI事業者の遵守は保証されない）
- プロフィール: 自己紹介140文字以内、アイコン設定（「記事をはじめて公開する前にやっておいてほしいこと」）
